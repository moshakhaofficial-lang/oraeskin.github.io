The basic rule is **thinnest to thickest**: water-based serums first, then creams, then oils. In the morning, finish with sunscreen.

A few combinations need care. **Don't use strong acids (AHA/BHA) and retinoids on the same night.** Alternate them. **Vitamin C works best in the morning** under sunscreen. **Niacinamide** pairs well with almost everything. Wait about a minute between layers so each one settles.

**Example routine:** AM: cleanser → vitamin C → niacinamide → moisturiser → sunscreen. PM: cleanser → BHA *or* retinoid (alternate nights) → moisturiser. These are the serums on Amazon India we rate most highly for each slot.
